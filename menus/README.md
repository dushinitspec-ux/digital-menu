# Меню сетей

Меню сети целиком в одном файле `menus/<сеть>/menu.json`, фото позиций лежат рядом.
Формат описан и проверяется схемой `menuFileSchema` в `packages/shared/src/menu-file.ts`.
Цены пишутся в обычных единицах: `185` — это 185 ₺. Цены по размерам задаются как `{ "S": 160, "M": 185 }`.

`demo/newyear-coffee.json` — демо-меню с примерными ценами для проверки шаблона и роликов. Это не меню клиента.

## Занести меню в систему

Импорт создаёт организацию, владельца, точки, категории, позиции с фото и сцены. С `--replace` меню и сцены
заменяются, а точки и экраны остаются: экраны переходят на сцены с теми же названиями.

```bash
OWNER_PASSWORD='…' pnpm --filter @dm/api import-menu -- ../../menus/<сеть>/menu.json --owner-email owner@example.com --owner-name "Имя" --owner-locale ru
```

Переменные окружения нужны те же, что у API (`DATABASE_URL`, `REGION` и т. д.). Турция живёт в контуре `eu`.

## Видеоролики для экранов

Для каждой сцены записывается ролик меню. Если в меню есть позиции с `"featured": true` (или с метками «новинка» и «акция»),
добавляется промо-ролик: по слайду на позицию и поздравление в конце. Формат MP4 H.264, 30 кадров/с,
1920×1080 и/или 1080×1920. Нужны ffmpeg и Chromium для Playwright (`npx playwright install chromium`).

```bash
pnpm --filter @dm/video render -- ../../menus/<сеть>/menu.json --orientation both
```

Готовые ролики появляются в `apps/video/output/`. Флаг `--list` показывает доступные ролики, `--only showcase` снимает только выбранные.
