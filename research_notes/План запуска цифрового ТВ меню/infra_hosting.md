## 1. RU-хостинг: Selectel, Yandex Cloud, Timeweb Cloud, VK Cloud (+ Reg.ru / Beget): VM, управляемый PostgreSQL, S3, CDN, 152-ФЗ

### Takeaway
Полностью подтвердить по официальному прайсу удалось только Yandex Cloud. ВМ 2 vCPU (100 %) / 4 ГБ / 40 ГБ SSD с публичным IP стоит около **3 499 ₽/мес с НДС**, минимальный управляемый PostgreSQL (b2.medium, 2×50 % vCPU / 4 ГБ, 20 ГБ SSD) — около **3 509 ₽/мес**. Платформа Yandex Cloud целиком работает по мерам для УЗ-1. По Selectel и Timeweb есть только сторонние ориентиры: около 3 230 ₽ и около 1 460–3 000 ₽ за ту же ВМ. По VK Cloud, Reg.ru и Beget цифр нет.

### Inferences
- Стартовый RU-контур на Yandex Cloud (с НДС) складывается так: ВМ Ice Lake 2×100 % / 4 ГБ / 40 ГБ SSD + IP ≈ 3 500 ₽; MPG b2.medium + 20 ГБ ≈ 3 510 ₽; S3 на 50 ГБ ≈ 116 ₽; один CDN-ресурс = 150 ₽ (до 150 ГБ), каждые следующие 100 ГБ ≈ 105 ₽; Postbox до 2000 писем бесплатно. Итого **≈ 7 300 ₽/мес**. Если держать PostgreSQL на той же ВМ и бэкапить WAL-G в холодный класс S3, получится **≈ 3 600–4 100 ₽/мес**, но администрировать базу придётся самим. Если взять ВМ с 20 % vCPU (≈2 460 ₽), выйдет дешевле, но для WebSocket-сервера доля 20 % рискованна.
- Для CDN на Yandex важно, что трафик «бакет → CDN» бесплатный. Тогда раздача медиа на ТВ стоит около 1,05 ₽/ГБ через CDN против 1,68 ₽/ГБ напрямую из S3. Каждый CDN-ресурс стоит 150 ₽/мес, даже если он простаивает, поэтому лучше держать один ресурс на все медиа.
- Отдельной надбавки за 152-ФЗ у Yandex, судя по документации, нет: меры УЗ-1 действуют для всей платформы, а не в отдельном «сегменте». Это нужно подтвердить у Яндекса. У Selectel аттестованный сегмент стоит на порядок дороже обычного облака (≥25 тыс. ₽/мес против ≈3 тыс. ₽).
- Для SaaS ТВ-меню (ПДн — это в основном контакты администраторов клиентов, то есть вероятно УЗ-4) аттестованный сегмент, скорее всего, не нужен. Но оператор всё равно обязан выполнить меры ПП-1119 / Приказа ФСТЭК №21 и хранить ПДн россиян в РФ. Уровень защищённости должен окончательно определить юрист (это параллельная задача по юр. требованиям).

## 3. CDN: Bunny.net, Cloudflare (Free, R2), блокировки и замедление иностранных CDN в РФ, российские CDN

### Takeaway
Cloudflare R2 подтверждён по официальной документации: **$0.015/ГБ·мес, egress бесплатный**, бесплатный уровень — 10 ГБ хранения, 1 млн операций класса A и 10 млн класса B в месяц. Это дешёвый вариант origin + раздачи для EU-контура. Для RU-контура иностранные CDN использовать рискованно. Есть подтверждённые российские варианты: Yandex Cloud CDN (150 ₽ за ресурс, 150 ГБ в пакете, дальше 1,054 ₽/ГБ) и Selectel CDN (ступенчатый тариф, по сторонним данным около 0,6 ₽/ГБ при объёме до 10 ТБ). Цены Bunny, EdgeCenter, NGENIX и CDNvideo, а также источники по замедлению Cloudflare в этой сессии не подтверждены.

### Inferences
- **EU:** R2 как origin для медиа плюс раздача через Cloudflare или Bunny. Пример: 100 ГБ медиа ≈ $1.35/мес за хранение (90 ГБ сверх бесплатных 10 ГБ × $0.015) при нулевом egress, плюс операции. При тысячах ТВ-плееров, которые качают обновления, бесплатный egress критичен.
- **RU:** для плееров в РФ медиа надёжнее раздавать из российского облака: Yandex Object Storage + Yandex Cloud CDN или Selectel S3 + Selectel CDN. Раздачу через Cloudflare, Bunny и других иностранных CDN для RU-клиентов закладывать не стоит: есть риск замедления, а также риск проблем с оплатой и передачей данных за границу.
- Плееры работают офлайн и качают медиа один раз, повторно — только при изменениях. Поэтому трафик CDN определяется числом экранов × объёмом изменённых медиа, а не постоянным стримингом. Для старта 150 ГБ из пакета Yandex CDN, скорее всего, хватит (оценка).

## 4. Real-time push на тысячи ТВ-экранов: Centrifugo, свой WS/SSE, Socket.IO, Mercure, Soketi, LISTEN/NOTIFY + Redis; Ably/Pusher; ёмкость небольшого VPS

### Takeaway
Centrifugo OSS распространяется под **Apache-2.0**. У него есть WebSocket, однонаправленный SSE (удобно для ТВ-браузеров), брокер на PostgreSQL 16+ (Redis не обязателен) и опубликованный бенчмарк: **1 млн WS-соединений ≈ 27 ГБ RAM (~30 КБ на соединение)** и ≈10 CPU на 1 млн простаивающих соединений. Значит, одна ВМ 2 vCPU / 4 ГБ с запасом держит тысячи и десятки тысяч экранов. PRO-версия коммерческая, цена только по запросу, продаётся только юрлицам. Soketi и Mercure распространяются под AGPL-3.0, Socket.IO и Laravel Reverb — под MIT. Цены Ably и Pusher в сессии не подтверждены.

### Cited Findings
- Centrifugo (OSS) — лицензия Apache License 2.0 — [centrifugo LICENSE](https://github.com/centrifugal/centrifugo/blob/master/LICENSE)
- Centrifugo PRO распространяется под коммерческой лицензией Centrifugal Labs LTD. «Pricing information… available upon request over sales@centrifugal.dev… exclusively available to corporate and business clients». Цена фиксированная (flat), зависит от размера компании и роли Centrifugo, включает 1 год приоритетной поддержки и обновлений, без лимитов. Sandbox без ключа: до 20 соединений, 2 нод и 5 API-запросов в секунду, для продакшена запрещён — [Centrifugo PRO overview](https://centrifugal.dev/docs/pro/overview) (прочитано в [github.com/centrifugal/centrifugal.dev, docs/pro/overview.md](https://github.com/centrifugal/centrifugal.dev/blob/main/docs/pro/overview.md))
- Что добавляет PRO: push-уведомления (FCM/APNs), трассировка, аналитика в ClickHouse, rate limits, SSO для админки, Connections API, user status, delta-компрессия и другое — [Centrifugo PRO overview](https://centrifugal.dev/docs/pro/overview)
- Транспорты Centrifugo: основной — WebSocket; есть эмуляция поверх HTTP-streaming и SSE, WebTransport экспериментально. Отдельно есть однонаправленный SSE (`uni_sse`) через стандартный EventSource без SDK — [Centrifugo highlights](https://centrifugal.dev/docs/getting-started/highlights), [Centrifugo uni_sse](https://centrifugal.dev/docs/transports/uni_sse)

PostgreSQL-контроллер для мультинодовых кластеров только на PostgreSQL тоже в OSS — [Centrifugo highlights](https://centrifugal.dev/docs/getting-started/highlights), [Centrifugo PRO overview](https://centrifugal.dev/docs/pro/overview)
- Бенчмарк Centrifugo (10.02.2020, сервер на библиотеке Centrifuge, Kubernetes, Xeon E5-2640 v4): 1 млн WebSocket-соединений, по 2 канала на каждое, ≈28 млн сообщений в минуту (~500 тыс./с) с p99 < 200 мс. Ресурсы: 20 подов × ~2 CPU = 40 CPU, **27 ГБ RAM (≈30 КБ на соединение)**, 5 шардов Redis по ~0,32 CPU. **Без активной рассылки на 1 млн соединений хватает ≈10 CPU** (уходит на connect/ping/pong). Буферы чтения и записи WS в тесте были уменьшены (настройка приведена в посте) — [Million connections with Centrifugo](https://centrifugal.dev/blog/2020/02/10/million-connections-with-centrifugo)
- Демо на чистом Go (epoll): «more than a million websockets connections with less than 1GB of ram». Автор прямо пишет, что это демонстрация, а не готовая реализация — [eranyanay/1m-go-websockets](https://github.com/eranyanay/1m-go-websockets)
- uWebSockets.js — нативный аддон для Node.js на C++. Сами авторы заявляют, что он «13x faster than Fastify» (заявление вендора). Лицензия Apache-2.0 там, где это явно указано — [uWebSockets.js README](https://github.com/uNetworking/uWebSockets.js)
- Лицензии (по LICENSE-файлам): Socket.IO — MIT ([LICENSE](https://github.com/socketio/socket.io/blob/main/LICENSE)); Soketi — AGPL-3.0 ([LICENSE](https://github.com/soketi/soketi/blob/master/LICENSE)); Mercure — AGPL-3.0 ([LICENSE](https://github.com/dunglas/mercure/blob/main/LICENSE)); Laravel Reverb — MIT ([LICENSE.md](https://github.com/laravel/reverb/blob/main/LICENSE.md)); Go-библиотеки WS: coder/websocket — ISC ([LICENSE.txt](https://github.com/coder/websocket/blob/master/LICENSE.txt)), lxzan/gws — Apache-2.0 ([LICENSE](https://github.com/lxzan/gws/blob/master/LICENSE))

### Inferences
- **Ёмкость небольшого VPS (оценка по бенчмарку Centrifugo):** при ~30 КБ на соединение 4 ГБ ВМ теоретически вмещает ~100 тыс. простаивающих соединений, если отдать WS-серверу ~3 ГБ. По CPU ~10 CPU на 1 млн простаивающих соединений дают ~0,1 CPU на 10 тыс. экранов. Для ТВ-меню с 1–10 тыс. экранов и редкими публикациями (меню меняется несколько раз в день) одна ВМ 2 vCPU / 4 ГБ имеет запас на порядок и больше. Ограничивать будут скорее ulimit/fd, keepalive через прокси и таймауты LB, чем RAM.
- **Минимальный стек для 1–3 разработчиков:** Centrifugo OSS + брокер PostgreSQL (без Redis). Бэкенд публикует событие «меню изменено» в той же транзакции, где сохраняет меню. Плеер держит SSE или WS, по событию забирает манифест через HTTP и докачивает медиа с CDN. Плюс к этому — периодический поллинг манифеста раз в N минут как страховка, если соединение потеряно.
- **Свой WS/SSE на Node.js или Go** вполне подходит на старте: один процесс, рассылка в памяти. Для нескольких нод нужен Redis pub/sub или PostgreSQL LISTEN/NOTIFY. Через NOTIFY стоит передавать только идентификатор изменения, а не данные.
- Soketi и Mercure под AGPL-3.0: если сервер модифицировать и отдавать по сети, нужно раскрыть изменения. Для неизменённого hub-сервиса это обычно приемлемо, но нужна юридическая оценка. Centrifugo (Apache-2.0) и Socket.IO (MIT) с этой точки зрения проще.
- **Ably и Pusher для RU-контура:** это иностранные сервисы. Данные проходят через их инфраструктуру за пределами РФ, оплата иностранным провайдерам из РФ затруднена, а сами соединения могут попасть под ограничения иностранного трафика, как описано в разделе 3 (не подтверждено). Поэтому для RU разумен self-hosted вариант. Для EU managed-сервисы технически возможны, но при тысячах постоянных соединений тарифы по concurrent connections, скорее всего, дороже одной ВМ (это вывод, цены не подтверждены).

### Gaps
- **Цены Ably и Pusher не подтверждены** (сайты недоступны, поиск исчерпан). Справочно, из памяти до 2026 года и **без проверки**: Pusher Channels Sandbox — бесплатно, 100 одновременных соединений и 200 тыс. сообщений в сутки; Startup — $49/мес, 500 соединений. У Ably бесплатный план с лимитом в пару сотен одновременных соединений. Перепроверить по ably.com/pricing и pusher.com/channels/pricing.
- Статус поддержки Soketi (дата последнего релиза) не проверен: GitHub API и страницы релизов недоступны, а в package.json версия `0.0.0-dev`.
- Лимит payload у PostgreSQL NOTIFY (по документации PostgreSQL — 8000 байт по умолчанию) в сессии не перепроверялся — [PostgreSQL NOTIFY](https://www.postgresql.org/docs/current/sql-notify.html) (не открывалось).
- Независимых свежих (2025–2026) бенчмарков Node.js `ws`, Socket.IO и SSE на маленьком VPS найти не удалось. Бенчмарк Centrifugo датирован 2020 годом.
- Нет данных о поддержке EventSource и WebSocket в конкретных ТВ-платформах (Tizen, webOS, Android TV WebView). Это смежная задача по ТВ-плееру.

- Для 1–3 разработчиков с админкой и плеером на веб-технологиях самый короткий путь — **TypeScript end-to-end**: SvelteKit или Next.js для админки, Hono или Fastify для API, общий код и типы с плеером, sharp для превью картинок, ffmpeg (CLI, вызывается как отдельный процесс, LGPL-сборка) для транскодирования видео. Real-time — Centrifugo или собственный SSE.
- Go — один бинарник, низкое потребление памяти на соединение, удобно для WS-шлюза. Elixir/Phoenix сильнее всего в real-time (Channels/PubSub из коробки), но нанимать под него в РФ и ЕС сложнее (вывод, без источника). Laravel + Reverb — зрелый вариант, если команда знает PHP.
- Supabase self-hosted тянет много компонентов (Postgres, GoTrue, PostgREST, Realtime, Storage, Kong и др.). Для двух независимых контуров это две отдельные инсталляции, и их сопровождение может перевесить экономию времени (вывод). PocketBase (SQLite, один бинарник) подходит для прототипа, но предупреждение о совместимости до v1.0 — риск для продакшена.
- imgproxy (Apache-2.0) как отдельный сервис ресайза «на лету» перед CDN избавляет от заранее нарезанных вариантов. Плеерам с офлайн-кэшем, впрочем, обычно достаточно один раз подготовить рендишены при загрузке (вывод).

## 6. Бэкапы и эксплуатация: бэкапы управляемых БД, pg_dump / WAL-G в другую зону, мониторинг и ошибки в своём регионе, транзакционная почта

### Takeaway
Yandex MPG по умолчанию хранит ежедневные автобэкапы **7 дней**. Срок настраивается от 7 до 60 дней, через политики — до 1095 дней. Хранение бесплатно в пределах объёма хранилища кластера, сверх него ≈2,21 ₽/ГБ·мес. Для независимых бэкапов подходят WAL-G (Apache-2.0) и pgBackRest (MIT), которые пишут в S3 другого провайдера внутри того же региона. Облачный Sentry может хранить события во Франкфурте, но учётные записи и метаданные организации всегда остаются в США. Self-hosted Sentry требует 4 CPU и 16 ГБ RAM + 16 ГБ swap и распространяется под FSL. В РФ транзакционную почту можно отправлять через Yandex Cloud Postbox (2000 писем в месяц бесплатно, дальше ≈80 ₽ за 1000). Scaleway TEM даёт 300 бесплатных писем в месяц.

### Cited Findings
- Yandex MPG: полная резервная копия всего кластера создаётся автоматически раз в день, отключить это нельзя. Первая и каждая седьмая копия — полные, остальные — инкрементные. Автобэкапы хранятся **7 дней по умолчанию, настраивается 7–60 дней**; через политики резервного копирования — 7–1095 дней. Ручные копии хранятся бессрочно. Бэкапы лежат в объектном хранилище и шифруются GPG. Восстановление идёт в новый кластер со скоростью около 10 МБ/с на ядро БД — [Yandex MPG: резервные копии](https://yandex.cloud/ru/docs/managed-postgresql/concepts/backup) (прочитано в [md-docs/managed-postgresql/concepts/backup.md](https://github.com/yandex-cloud/docs/blob/master/md-docs/managed-postgresql/concepts/backup.md))
- Yandex MPG: бэкапы бесплатны, пока их объём ≤ суммарного объёма хранилищ хостов. Сверх этого — 0,00307 ₽ за ГБ·ч (≈2,21 ₽/ГБ·мес, с НДС) — [Yandex MPG pricing](https://yandex.cloud/ru/docs/managed-postgresql/pricing)
- Холодный класс Yandex Object Storage для внешних бэкапов стоит ≈1,27 ₽/ГБ·мес, ледяной — ≈0,63 ₽/ГБ·мес, но при удалении раньше 12 месяцев доплачивается остаток — [Yandex Object Storage pricing](https://yandex.cloud/ru/docs/storage/pricing). Cloudflare R2 Infrequent Access — $0.01/ГБ·мес, минимальный срок хранения 30 дней, извлечение — $0.01/ГБ — [Cloudflare R2 pricing](https://developers.cloudflare.com/r2/pricing/)
- Scaleway Managed DB: автобэкапы удаляются по истечении срока, заданного в расписании бэкапов — [Scaleway: manage backups](https://www.scaleway.com/en/docs/managed-databases-for-postgresql-and-mysql/how-to/manage-backups/)
- Лицензии инструментов: WAL-G — Apache-2.0 ([LICENSE.md](https://github.com/wal-g/wal-g/blob/master/LICENSE.md)); pgBackRest — MIT ([LICENSE](https://github.com/pgbackrest/pgbackrest/blob/main/LICENSE)); Uptime Kuma — MIT ([LICENSE](https://github.com/louislam/uptime-kuma/blob/master/LICENSE))
- Sentry SaaS: регион хранения (US — Айова, EU — Франкфурт) выбирается при создании организации и потом не меняется. В выбранном регионе хранятся события ошибок, транзакции, спаны, логи, реплеи и их бэкапы. **Независимо от выбора в США хранятся** учётные записи пользователей, настройки и аудит-логи организации, токены, cron check-ins и метаданные проектов — [Sentry: Data Storage Location](https://docs.sentry.io/organization/data-storage-location/) (прочитано в [getsentry/sentry-docs](https://github.com/getsentry/sentry-docs/blob/master/docs/organization/data-storage-location/index.mdx))
- Self-hosted Sentry: минимум 4 CPU, 16 ГБ RAM + 16 ГБ swap, 20 ГБ диска, рекомендуется 32 ГБ RAM. Все сервисы, включая Kafka и ClickHouse, работают на одной машине — [Sentry self-hosted docs](https://develop.sentry.dev/self-hosted/) (прочитано в [sentry-docs/develop-docs/self-hosted/index.mdx](https://github.com/getsentry/sentry-docs/blob/master/develop-docs/self-hosted/index.mdx)). Лицензия Sentry и self-hosted — **FSL-1.1-Apache-2.0** (Functional Source License, со временем переходит в Apache-2.0) — [sentry LICENSE.md](https://github.com/getsentry/sentry/blob/master/LICENSE.md), [self-hosted LICENSE.md](https://github.com/getsentry/self-hosted/blob/master/LICENSE.md)
- Yandex Cloud Postbox (с НДС, с 30.04.2026): первые 2000 писем в месяц бесплатно. Дальше 80,32 ₽ за 1000 (2–10 тыс.), 70,15 ₽ (10–50 тыс.), 59,98 ₽ (50–100 тыс.), 39,65 ₽ (100–250 тыс.) и далее до 6,1 ₽ за 1000 при объёме больше 50 млн — [Yandex Cloud Postbox pricing](https://yandex.cloud/ru/docs/postbox/pricing) (прочитано в [md-docs/postbox/pricing.md](https://github.com/yandex-cloud/docs/blob/master/md-docs/postbox/pricing.md)). Пример: 10 000 писем в месяц ≈ 642,5 ₽ (8 × 80,32).
- Scaleway Transactional Email: оплата за число отправленных писем сверх включённых в план. Бесплатный уровень — 300 писем в месяц — [Scaleway TEM FAQ](https://www.scaleway.com/en/docs/transactional-email/faq/)

### Inferences
- **RU:** Yandex MPG с автобэкапами (стоит поднять срок до 14–30 дней) плюс еженедельный pg_dump или постоянный WAL-G в бакет **другого российского провайдера** (например, Selectel S3 холодного класса). Так бэкап переживёт проблемы с аккаунтом или регионом. Хранить бэкапы RU-контура в EU нельзя: это трансграничная передача ПДн.
- **EU:** WAL-G или pgBackRest из Hetzner в R2 или Scaleway Object Storage (другой провайдер, тоже в ЕС).
- **Ошибки и мониторинг:** у Sentry SaaS в EU-регионе часть метаданных (учётные записи, настройки) всё равно хранится в США. Если в событиях нет ПДн (с scrubbing), это, вероятно, допустимо для EU-контура при наличии DPA. Для RU-контура лучше self-hosted. Self-hosted Sentry (16–32 ГБ RAM) слишком тяжёл для маленького бюджета; GlitchTip (совместим с Sentry SDK) или логи плюс Uptime Kuma (MIT) в каждом регионе — более лёгкие варианты.
- **Почта RU:** Postbox — самый дешёвый подтверждённый вариант для транзакционных писем, если инфраструктура и так в Yandex Cloud.
